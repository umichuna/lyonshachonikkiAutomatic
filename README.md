# 社長日記 自動生成・公開システム

タイトル・本文・写真を入力するだけで、社長日記のHTML記事を生成し、GitHub Pagesでの公開URL発行とスプレッドシートへの記録までを自動化するシステムです。

詳細な要件は [`要件定義書.MD`](./要件定義書.MD) を参照してください。

## 構成

| ファイル/フォルダ | 内容 |
|---|---|
| `app.html` | 入力アプリ本体。ブラウザで開くだけで動く単一HTML(タブ切り替え式・3画面) |
| `template/article-template.html` | 記事の共通デザインテンプレート(Vol.001〜004と同一デザイン) |
| `gas/code.gs` | Google Apps Script バックエンド。GitHubへのHTML登録とスプレッドシート記録を代行する中継役 |
| `past-articles/` | 生成された記事HTML(`volXXX.html`)の保存先 |
| `docs/SETUP.md` | 初回セットアップ手順 |
| `syachonikkigenerate.py` / `lyonshachonikkiUI.HTML` | 開発時の参考資産(Python版生成ロジック・UIモック) |

## 全体フロー

```
入力アプリ(app.html)
  ①記事作成(見出し・本文・写真・シリーズ見出し) → ②プレビュー・掲載 → ③掲載履歴
        ↓「掲載する」
GAS(gas/code.gs)が中継
   ├─ 同じVol番号の記事が既にないかチェック
   ├─ GitHub Contents API で past-articles/volXXX.html へcommit
   └─ スプレッドシートへ1行追記(更新日/掲載終了日/タイトル/URL/処理/取り消し)
        ↓
GitHub Pagesが自動デプロイ → 公開URL発行
```

## 主な機能

- **記事の作成・掲載**: 見出し・本文・写真(全体4枚/1見出し2枚まで)をブロック単位で入力。太字・下線・マーカー・枠で囲む の装飾に対応
- **シリーズもの(任意)**: 連載記事に「✦ ルーツ編・その四 ✦」のような見出しと章末メッセージを付けられる
- **修正**: 掲載直後、または③掲載履歴からいつでも上書き更新できる(行は増えず、スタッフへの再通知も飛ばない)
- **取り消し**: 掲載した記事を取り下げられる(掲載終了日を今日にし、F列に「取り消し」を記録。ファイルとVol番号は残るので採番はずれない)
- **チュートリアル**: 初回起動時と「❓使い方」ボタンから、操作手順を画面上で案内

## セットアップ

初回のみ、GitHubトークンの発行・GitHub Pagesの有効化・GASのデプロイが必要です。
手順は [`docs/SETUP.md`](./docs/SETUP.md) を参照してください。
